Install guide

Install Breather and open it the first time.

Breather is free and open source. Because it isn't notarized by Apple (that needs a paid developer account), macOS asks you to approve it once. Here are three ways to install it. The first two skip that step entirely.

Option 1 · Homebrew · easiest

$brew install --cask jals413/tap/breather

Breather's tap clears macOS's download quarantine as it installs, so it opens straight away. Don't have Homebrew? brew.sh.

Option 2 · One line in Terminal

$curl -fsSL https://jals413.github.io/breather/install.sh | bash

Downloads the latest release from GitHub, verifies its SHA-256 checksum, installs it to Applications, clears the quarantine and opens it. Read the script.

Option 3 · Download the DMG

Download and drag to Applications

Get Breather.dmg, open it, and drag Breather onto the Applications folder.

Open Breather. macOS stops it.

Double-click Breather in Applications. macOS shows a message like this one. Click Done.

“Breather” Not Opened

Apple could not verify “Breather” is free of malware that may harm your Mac or compromise your privacy.

DoneMove to Bin

Open Privacy & Security

Open System Settings → Privacy & Security, and scroll down to Security. You'll see a line about Breather. Click Open Anyway. It appears for about an hour after you try to open the app.

Privacy & Security
Security
“Breather” was blocked to protect your Mac. Open Anyway

Confirm

Click Open Anyway once more and enter your Mac password (or use Touch ID). Breather opens, and macOS remembers your choice. You won't be asked again.

Prefer Terminal?

This removes the download quarantine from Breather only. It doesn't change security settings for any other app.

$xattr -dr com.apple.quarantine /Applications/Breather.app

After it opens

Breather lives in your menu bar and your notch, so there's no Dock icon. The welcome screen lets you pick a rhythm and turn on Open at login. macOS may ask for permissions later, only when you turn on the features that need them: Bluetooth and Local Network for the iPhone link, and Automation if you enable website stats.

Questions

Is Breather really free?

Yes. It's free and open source under the GNU GPL v3.0, with no trials, subscriptions or accounts.

Which Macs does it run on?

Any Mac running macOS 26 Tahoe or later, including macOS 27, on Apple silicon or Intel. On Macs without a notch, alerts appear as a floating pill under the menu bar.

How do I update?

Breather tells you in the notch when a new version is out. With Homebrew, run brew upgrade --cask breather. Otherwise run the one-line installer again or download the new DMG.

“Breather is damaged and can't be opened”

That's macOS's quarantine message for apps that aren't notarized, not real damage. Run the Terminal command above, or reinstall with Homebrew or the one-line installer.

I don't see “Open Anyway”

Try opening Breather again first. The button only appears for about an hour after macOS blocks it. Still nothing? Use the Terminal command above.

“Breather requires macOS 26 or later”

Breather uses features introduced in macOS 26 Tahoe. Update in System Settings → General → Software Update.

Is it safe to approve an app Apple didn't check?

Only approve apps you trust. Breather's full source is on GitHub, every release is built there by GitHub Actions from the tagged code, and each release lists SHA-256 checksums so you can verify the download: shasum -a 256 Breather.dmg.

How do I uninstall?

Quit Breather from the menu bar and move it to the Bin. To also remove its data, delete ~/Library/Application Support/Breather and ~/Library/Preferences/com.jalthakor.breather.plist. With Homebrew: brew uninstall --zap --cask breather.
