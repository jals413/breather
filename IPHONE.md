# Breather for iPhone: plan

**Status:** built. The iPhone app, Live Activity, notification extension, Apple Watch app and complications all exist. Paid-account features (Apple push, Screen Time blocking) are compiled behind the `BREATHER_PAID` flag and switch on with the Paid build configuration.

## Run it

| What | Command |
|---|---|
| Mac app (free) | `scripts/build.sh --install --run` |
| Mac app (paid: Apple push) | `BREATHER_PAID=1 scripts/build.sh --install --run` |
| iPhone + Watch in the Simulator | `scripts/mobile.sh sim` |
| iPhone + Watch on your devices | `scripts/mobile.sh device <TEAM_ID>` (free Apple ID works; reinstall every 7 days) |
| Paid configuration | `PAID=1 scripts/mobile.sh device <TEAM_ID>` |

Then on the Mac: **Settings → iPhone & Apple Watch** → turn on → **Pair a New iPhone…** and type the code on the phone.

## Free vs paid builds

| | Free (Debug/Release) | Paid (DebugPaid/ReleasePaid) |
|---|---|---|
| Link | Bluetooth (background) + local network (app open / Simulator) | + Apple push from anywhere |
| Lock Screen / Dynamic Island | Starts when you open the app; updates in the background over Bluetooth | Also starts by push, even with the phone asleep |
| Apple Watch | App, complications, Smart Stack, haptic via notifications | Same |
| Block apps during breaks | – | Screen Time shield (app + Notification Service Extension) |

## What it does

When a break starts on the Mac:

1. **The iPhone shows a Live Activity.** It's a countdown on the Lock Screen and in the Dynamic Island, with the break name and the end time. Apple Watch mirrors it in the Smart Stack with a haptic tap.
2. **The iPhone blocks distracting apps** with a Screen Time shield, until the break ends. You choose which apps (or "all except essentials"), and there's a "Force unblock" escape hatch.

When the break ends, the Live Activity ends and the shield lifts.

## How the Mac reaches the phone

```
Mac (Breather)                         Apple Push (APNs)                    iPhone
break starts ──► signed HTTP/2 request ──►  push-to-start Live Activity  ──►  Lock Screen + Dynamic Island
                                         + alert push                  ──►  Notification Service Extension
                                                                              └─ applies the Screen Time shield
break ends   ──► "end" push            ──►  Live Activity ends, shield cleared
```

- **Push-to-start Live Activities (iOS 17.2+)** arrive even in Low Power Mode with Background App Refresh off. That's the same approach LookAway uses.
- **The shield is applied by a Notification Service Extension.** Alert pushes reliably run that code. Silent pushes are throttled, so the extension is the dependable path.
- **Pairing:** the phone shows a QR code / 6-digit code holding its push tokens, and the Mac stores them in the Keychain.
- **Personal use:** the Mac signs pushes itself with your APNs key (`.p8`). No server is needed.
- **Selling it:** the key can't ship inside the app, so it would move to a tiny relay server (one endpoint, about 50 lines).

## What needs the paid account

| Piece | Free Apple ID | Paid ($99/yr) |
|---|---|---|
| iOS app on your iPhone | Yes, but it expires after 7 days | Yes |
| Live Activity UI, Dynamic Island, Watch | Yes, started from the app | Yes |
| Push to the phone (APNs key) | **No** | Yes |
| Screen Time blocking (Family Controls entitlement) | **No** | Yes (development), with Apple approval for App Store distribution |
| Everything in the iOS Simulator | **Yes, with no account** | Yes |

## Testing now, without the account

- **Simulator transport.** The Mac app can send the exact same payloads to the iOS Simulator with `xcrun simctl push`. So a real Mac break can start a Live Activity in the simulated iPhone's Dynamic Island today.
- **Screen Time code** is written and compiles. It only runs on a real device with the entitlement, so it stays behind the flag.
- **Mac settings:** an "iPhone (preview)" pane appears only when the feature flag is on. `defaults write com.jalthakor.breather feature.iphone -bool YES` turns it on.
